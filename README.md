# InkRSS

RSS-ленты на электронных книгах PocketBook: утренний выпуск, который листается кнопками, как книга. Полный текст статей и картинки — через ваш сервер [Miniflux](https://miniflux.app), чтение без интернета после обновления.

*[English version](README.en.md) · Сайт: [0rb1ta.github.io/InkRSS](https://0rb1ta.github.io/InkRSS/)*

Из серверов пока поддерживается только **Miniflux** (свой или на хостинге). Без сервера ленты тоже читаются — напрямую с сайтов, но без полного текста.

## Что умеет

- подключение к Miniflux по логину и паролю или по ключу API — на экране или файлом `config.json`;
- выпуск: главная статья, разделы по папкам или лентам, у каждой статьи — лента и время чтения;
- полный текст: короткие статьи сервер достаёт со страницы сайта;
- чтение без сети: тексты и картинки (в оттенках серого, под ширину экрана) скачиваются по кнопке «Обновить»;
- «прочитано» и «избранное» синхронизируются с Miniflux; отметки без сети копятся и уходят при следующем обновлении;
- «Прочитать всё» для выпуска, ленты и папки;
- статья постранично, листание кнопками и свайпом; шрифт (PT Serif, Literata, Roboto и шрифты читалки) и размер — прямо в меню;
- QR-код ссылки на оригинал — открыть на телефоне;
- без сервера: добавление ленты по адресу, импорт OPML;
- русский и английский интерфейс.

## Установка

Проверено на PocketBook 970 (InkPad Lite), прошивка 6.8. На других моделях с прошивкой 6.x приложение, скорее всего, запустится, но это не проверено — напишите в [Issues](https://github.com/0rb1ta/InkRSS/issues), работает ли: модель, версия прошивки и, если что-то не так, файл `system/inkrss/log.txt`.

1. Подключите читалку к компьютеру по USB.
2. Скопируйте содержимое архива релиза в корень внутренней памяти: `applications/InkRSS.app`, `applications/icons/` и папку `system/inkrss/`.
3. Отключите читалку и запустите InkRSS из раздела «Приложения».

### Обновления

После первого удачного обновления лент приложение проверяет, есть ли на GitHub новый релиз. Если есть — в шапке главного экрана появляется значок со стрелкой; по нажатию открывается QR-код со страницей релиза. Новую версию копируют так же, поверх старых файлов: подключение и скачанные статьи сохранятся.

Удаление: удалите `applications/InkRSS.app`, файлы `applications/icons/inkrss*.bmp` и папку `system/inkrss/`. Если значок был добавлен в меню «Приложения», сначала уберите его в настройках.

### Подключение к Miniflux

Введите адрес сервера и логин с паролем (или ключ API: Miniflux → Настройки → Ключи API). Чтобы не печатать на экранной клавиатуре, можно положить файл `system/inkrss/config.json`:

```json
{ "mode": "miniflux", "server": "https://rss.example.org", "token": "ключ API" }
```

Полный текст лучше всего включить в самом Miniflux: в настройках ленты — «Fetch original content». Для коротких статей InkRSS просит сервер сделать это сам.

### Без сервера

Нажмите «Без сервера: ленты напрямую». Ленты добавляются по адресу («Ленты и папки» → «+») или из файла `.opml` в корне памяти читалки.

## Известные ограничения

- Из серверов — только Miniflux. Самоподписанные сертификаты не поддерживаются.
- Прошивка сама выключает Wi-Fi: приложение включает его перед обновлением, это занимает несколько секунд.
- Обновление — только по кнопке, до 200 новых статей за раз (меняется в настройках).

## Сборка

Нужен PocketBook SDK B288 6.8 (`github.com/pocketbook/SDK_6.3.0`, релиз 6.8).

```bash
app/package/build-device.sh
```
